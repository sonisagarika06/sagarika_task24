# ReactJS - Hello World

A simple React application built with Vite that displays **"Hello, World!"** in the browser.

## Features

- Built with React and Vite
- Clean centered UI displaying `"Hello, World!"`

## Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm

## Getting Started

1. Navigate to the project folder:
   bash
   cd sagarika_task24
   

2. Install dependencies:
   bash
   npm install
   

3. Start the development server:
   bash
   npm run dev
   

4. Open the local URL shown in the terminal (typically `http://localhost:5173`) in your browser.

## Build for Production

bash
npm run build


The production-ready static files will be generated inside the `dist/` directory, which can be deployed to platforms like Netlify, Vercel, or GitHub Pages.
